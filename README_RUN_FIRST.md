# Bharat Sign AI 3 – Universal Indian Language & Sign Language Translation Platform

> **"Connecting Languages. Empowering Communication. Breaking Barriers."**

Bharat Sign AI 3 is an advanced AI-powered accessibility platform bridging spoken/written languages and Indian Sign Language (ISL) across English and 14+ Indian regional languages.

---

## 🌟 Master Operating Modes

1. **Mode 1: Text → Indian Sign Language (ISL)**
   - Type in English or any Indian language to generate grammatically correct ISL animations on the 3D Mixamo avatar.

2. **Mode 2: Voice & Audio → Indian Sign Language (ISL)**
   - Real-time microphone speech recognition (Web Speech + Whisper AI) and audio file upload (`.mp3`, `.wav`, `.m4a`, `.webm`).

3. **Mode 3: Universal Semantic Layer & 14+ Regional Indian Languages → ISL**
   - Direct support for **Hindi, Bhojpuri, Marathi, Bengali, Gujarati, Punjabi, Tamil, Telugu, Malayalam, Kannada, Odia, Assamese, Urdu, Sanskrit**.
   - Universal intermediate semantic representation (Time + Subject + Object + Verb + Negation/Question).

4. **Mode 4: Camera / Video Sign Language Recognition → English**
   - Real-time computer vision hand landmark tracking & ISL gesture classification with confidence scoring and alternative predictions.

5. **Mode 5: Sign Recognition → Regional Indian Languages + Voice Output (TTS)**
   - Translates detected signs into selected Indian regional language and speaks out aloud via multi-lingual speech synthesis.

6. **Mode 6: Live Two-Way Communication Studio**
   - Split-screen live room for interactive conversation between Hearing persons and Deaf individuals.

7. **ISL Interactive Dictionary & Learning Studio**
   - 100+ standard signs across categories (Greetings, Emergency, Education, Food, Basics), plus complete **A-Z Fingerspelling** and **0-9 Numbers**.

## 🧪 Demonstration Examples

- **Bhojpuri**: "हम स्कूल जा तानी।" → ISL Gloss: `ME SCHOOL GO`
- **English**: "I am going to college tomorrow." → ISL Gloss: `TOMORROW ME COLLEGE GO`
- **Hindi**: "मुझे पानी चाहिए।" → ISL Gloss: `ME WATER WANT`
- **Telugu**: "నాకు నీళ్లు కావాలి।" → ISL Gloss: `ME WATER WANT`
- **Camera Signs**: Wave for `HELLO`, Chin tap for `THANK YOU`, Big wave for `GOODBYE`, Thumbs up for `YES`, V sign for `WATER`.
